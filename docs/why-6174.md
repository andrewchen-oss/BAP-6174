# Why 6174

> *"The absent-minded clerk of a mathematician friend has just discovered something about four-digit numbers."*
> — after D. R. Kaprekar, *Scripta Mathematica*, 1949

In 1949, D. R. Kaprekar observed that any four-digit number whose digits are not all identical converges, under repeated application of a simple subtraction operation, to the fixed point **6174** in at most seven iterations. The operation is deterministic, purely mechanical, and invariant to starting position.

## The routine

Given a four-digit number `N` (digits not all equal):

1. Sort the digits of `N` in descending order → `N_high`.
2. Sort the digits of `N` in ascending order → `N_low`.
3. Compute `N' = N_high − N_low`. Pad `N'` back to four digits with leading zeros.
4. Set `N = N'`. Repeat.

## Example — seed `3524`

| Step | `N_high` | `N_low` | `N_high − N_low` |
|---|---|---|---|
| 1 | 5432 | 2345 | **3087** |
| 2 | 8730 | 0378 | **8352** |
| 3 | 8532 | 2358 | **6174** |
| 4 | 7641 | 1467 | **6174** ← fixed point |

## Universality

| Seed | Steps to 6174 |
|---|---|
| 1234 | 3 |
| 5678 | 6 |
| Any four-digit number (digits not all equal) | ≤ 7 |
| 7777 (all digits equal) | Excluded — the routine is undefined |

## Why this name for a protocol

BAP-6174 is named after this constant as a statement about its design philosophy:

> Any sufficiently honest specification of what autonomous agents need converges to the same set of primitives — identity, verifiable capability, reputation, economic rights, and operational control. The exact path from starting assumptions to the protocol may differ, but the destination is invariant.

Six specifications. Twelve invariants. One fixed point.
